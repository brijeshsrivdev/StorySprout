# StorySprout Roadmap

This roadmap is directional only. A roadmap item is not authorization to implement it.

## Phase 0 — Repository foundation
**Status:** Complete

Monorepo, baseline services/packages, Composition Model, local PostgreSQL/MinIO, and CI foundation.

## Phase 1 — Product shell
**Status:** Planned

Creator-facing project/dashboard and initial screen shell with realistic states.

## Phase 2 — Editor and Composition
**Status:** Planned

Connect editor interactions to the canonical Composition Model and establish reliable serialization/versioning.

## Phase 3 — Persistence
**Status:** Planned

Persist projects, stories, scenes, characters, assets, and compositions through specified APIs.

## Phase 4 — AI generation
**Status:** Planned

Introduce provider-independent AI gateways/adapters for explicitly specified generation features.

## Phase 5 — Rendering
**Status:** Planned

Implement composition rendering, audio composition, render jobs, FFmpeg, and output artifacts around the canonical model.

## Phase 6 — Production hardening
**Status:** Planned

Content safety, security, observability, performance, deployment and publishing-related capabilities as separately specified.
