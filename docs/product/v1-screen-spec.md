# V1 screen specification

1. Dashboard — project list and create/open story entry points.
2. Create Story — AI-assisted or blank story start.
3. Story Setup — idea, target age, duration, visual style, language.
4. Story Outline — editable AI-generated outline and scene ordering.
5. Characters — select/create character assets.
6. Scene Setup — backgrounds, characters, props, dialogue and actions.
7. Editor — assets, canvas, properties and timeline workspace.
8. Preview — playback before render.
9. Render — output settings, job progress and final MP4.

Each important screen needs idle, loading, ready, saving and error states. AI generation additionally needs generating and generation-failed states; rendering needs queued, rendering, completed and failed states.
